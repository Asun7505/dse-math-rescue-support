DSE MATH RESCUE

私隱政策

學習紀錄保存在你的裝置。啟用購買服務後，Apple 與 RevenueCat 會處理驗證購買所需的資料。

本政策適用於 DSE 數學急救站 iPhone App 及本支援網站。提供者為 App Store 所列的開發者 Yik Ho Tsang（下稱「我們」）。

1. 學習資料

App 在裝置內的 SQLite 資料庫保存年級、語言、練習目標、作答選項、對錯、用時、提示使用情況、活動進度、診斷及分析結果。題目、出題與學習分析均在本機處理；本 App 不會把這些學習紀錄上傳給我們、Apple 的購買服務或 RevenueCat。

App 沒有學生帳戶、聊天、廣告、AI API 或學習紀錄雲端同步功能，也不要求提供姓名、學校或電郵。裝置作業系統的備份可能包含 App 本機資料，視乎你的備份設定。

2. 購買服務處理的資料

購買服務啟用後，App 會連接 RevenueCat 檢查購買權限，包括未購買用戶。服務會處理匿名 App User ID、商品及交易識別碼、購買／恢復／退款狀態、交易時間、商店地區與貨幣，以及服務運作所需的技術資料，例如 App／作業系統版本和網絡連線資料。匿名識別碼不等於完全沒有資料處理。

這些資料用於驗證交易、解鎖功能、恢復購買、防止欺詐及查看購買統計。Apple 處理付款帳戶及付款方式；我們的 App 不接收信用卡號或銀行資料。我們沒有向 RevenueCat 提供學生姓名、電郵或答題紀錄，也沒有啟用額外 SDK 診斷或自動裝置識別碼收集選項。

我們不出售學習或購買資料，也不使用資料作跨 App 廣告追蹤。

3. 服務供應商及資料傳輸

付款由 Apple App Store 處理，購買驗證由 RevenueCat 提供。服務供應商可能在香港以外處理資料；RevenueCat 說明其客戶資料會傳送至美國的 AWS 資料中心。詳情見 Apple 私隱政策及 RevenueCat 私隱政策。

本網站由 GitHub Pages 託管，沒有額外分析程式、廣告或追蹤像素。GitHub 為安全目的會記錄訪客 IP 地址；詳情見 GitHub 私隱聲明。

4. 保存、刪除及你的要求

學習紀錄會留在本機，直至相關 App 資料被刪除。在 iPhone「刪除 App」通常會移除本機資料；「卸載 App」則可能保留資料。刪除本機資料不會自動刪除 Apple／RevenueCat 的交易資料或裝置備份，也不會自動退款。恢復購買只恢復使用權，不會恢復學習紀錄。

購買資料會按驗證及恢復使用權、處理退款、防止欺詐及法律要求所需保留。我們不把所有資料一概永久保存；會按用途及服務商的保留規則處理。你可以聯絡我們要求查詢、更正或刪除我們持有的相關資料；我們會核實所需資料並與服務商協調，法律或交易紀錄保留要求可能限制刪除。刪除購買識別資料亦可能影響恢復購買。

由於學習資料未上傳，我們無法遠端查看、修復或刪除你的本機答題紀錄。如你電郵求助，我們會處理你提供的地址、訊息及附件，用於回覆及處理問題，並在問題處理及必要保留期間後刪除不再需要的內容。

5. 未成年用戶

本 App 為中學生提供練習。未成年用戶應在家長或監護人協助下處理購買及個人資料事項。請勿在求助訊息中提供學生姓名、學校、證件資料或其他不必要的個人資料；家長或監護人可以代為聯絡我們。

6. 聯絡及政策更新

私隱查詢、更正或刪除要求：ryo.studio@outlook.com。請註明「DSE 數學急救站私隱查詢」。請勿傳送 Apple 密碼、驗證碼或完整付款卡資料。

如資料處理方式改變，我們會更新本頁日期，並按變更需要透過 App 或商店說明通知用戶；需要同意時會另行取得同意。
